# Student Result Management System (Python)

## Project Description

The Student Result Management System is a menu-driven Python application that allows users to manage student academic records.
The system enables adding student details, calculating results based on subject marks, and displaying final results including total marks, percentage, grade, and pass/fail status.

This project is built using core Python concepts and is suitable for beginners learning data handling and program logic.

The application runs continuously until the user chooses to exit.

---

## Features

* Add student details with multiple subject marks
* Automatic calculation of total marks and percentage
* Grade and pass/fail status evaluation
* Display complete student result details
* Menu-driven interface
* Simple terminal-based interaction

## Result Evaluation Criteria

* Percentage ≥ 75 : Distinction
* Percentage ≥ 60 : First Class
* Percentage ≥ 40 : Second Class
* Percentage < 40 : Fail
